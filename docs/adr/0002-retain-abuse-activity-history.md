# Retain IP-linked abuse activity without automatic expiry

Retain the source IP address for paste creation, account creation, and successful sign-ins indefinitely to support abuse investigations.
This choice preserves account and paste attribution beyond a fixed investigation window, at the cost of retaining identifiable activity and increasing storage use.
Public reads do not belong to this history; visitor measurement uses a separate policy.

Katbin does not store these records before this feature, so the history starts when collection begins.
